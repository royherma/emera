# Security policy

## Reporting a vulnerability

Email **oss@techguyverlabs.org** with what you found, steps to reproduce, and the version or commit. Please do not open a public issue or pull request for a security problem.

We reply within 5 days, tell you what we plan to do, and credit you in the fix unless you prefer to stay anonymous.

## Scope

The API (`apps/api`), the site (`apps/site`), the app (`apps/mobile`) and the AT Protocol lexicons (`lexicons/`). Reports about accounts, uploads, sign-in, provenance checks and takedown handling are especially welcome.

## Supported versions

Only the latest commit on `main` is supported.
