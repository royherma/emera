# Agent entry point

Before working, read [CLAUDE.md](CLAUDE.md) in this checkout in full. It is the one rulebook for every agent, delegated ones included: layout, ports, environments, deploy and publishing rules, and which folder each workstream owns.

Several agents work here at once: run `npm run agents` and follow "Working in parallel" in CLAUDE.md before your first edit.

Keep shared rules in `CLAUDE.md`. Don't copy them here.
