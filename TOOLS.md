# Tools

| Job | Tool script | Run it | Writes to | Area |
| --- | --- | --- | --- | --- |
| Plan: every step + decision + name options, click to decide, each click reaches Claude | `plan/server.mjs` | `npm run plan` (http://agora.localhost:5035) | `data/plan.json`, `data/feedback.jsonl` | Plan |
| Atlas: a live map of the product built from the code - stories, flows, system graph, coverage, platforms | `tools/atlas/build.mjs` | `npm run atlas` (http://agora.localhost:5035/atlas) | `data/atlas.json`, reads `docs/stories.yaml` | Plan |
| Atlas screens: exports the Expo web build in mock mode, signs in, captures every screen (phone and desktop, day and night, plus menu/empty/error states) | `tools/atlas/shots.mjs` | `npm run atlas:shots` or `node tools/atlas/shots.mjs` (re-run after the app changes) | `data/atlas-shots/<screen>/*.png`, `data/atlas-shots/index.json`, then rebuilds `data/atlas.json` | Plan |
| Import old posts: turns an Instagram "Download your information" export (zip or folder, JSON) or a plain folder of images into Emera posts through the real API; dry-run table, resumable | `tools/import/import.mjs` | `node tools/import/import.mjs <export.zip\|folder> --api <url> --token <session token> [--dry-run] [--limit N]` | Emera posts via `/v1/uploads` + `/v1/posts`; `tools/import/state/*.json` | Import |
| Brand kit: logo PNGs (Sora lockup), mark SVGs, app icons, the app's icons as SVG, color CSS/JSON and one zip, shown at https://emera.social/brand/ | `brand/kit/build.mjs` | `node brand/kit/build.mjs`, then `node apps/site/scripts/build.mjs` | `apps/site/public/brand/files/` | brand |
| Phone screens: every screenshot from the iOS / Android test run, filling in live as the run takes it | `plan/screens.mjs` + `.github/scripts/stream-shots.sh` | `npm run plan` (http://agora.localhost:5035/screens), run starts with `gh workflow run native.yml -f platform=ios` | `ci-shots` branch, `runs/<run id>/<platform>/` | Plan |
| Production check: two test accounts walk every core flow on the live API (handle, photo + video post, feed, public pages, follow, like, comment, notifications, search, copy report, flag, DMs, channels, invite, mute/block, delete post, delete accounts) and print PASS/FAIL per flow | `tools/prod-check.mjs` | `TOKEN_A=<token> TOKEN_B=<token> node tools/prod-check.mjs [api url]` (tokens from two fresh sign-ins; both accounts are deleted at the end) | nothing kept; posts and accounts are deleted | Ops |
