# Naming

`agora` is the folder code name only (Greek public square: where people gather to share). It is not the brand.

## What the name must do

- Feel inclusive: a place to express and share, not a jab at Instagram.
- Say "your work is safe here" without sounding legal or defensive.
- A domain we can buy at a normal price.
