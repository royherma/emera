# Naming patterns: what 2023-2026 launches did, and rules to name against

Written 2026-11-13. Nothing bought or registered. No availability checked for any name below.

## Scope (corrected 2026-11-13)

Not a photographers' app. It is for every kind of creator and creative work: video, illustration, music, design, physical products and objects, in a world where AI makes any of it easy to copy. So names and domains must not say photo, camera, frame, shot or lens. Photo-only names in the lists below (Glass, Locket, Retro) are kept as evidence of how names work, not as models for ours.

## 2. Rules (what the rejected list breaks)

1. **One real word, big meaning, wrong category.** Linear, Arc, Granola, Glass, Locket, Cursor. A common noun used where nobody expects it. Rejected list is the opposite: made-up compounds (Folioproof, Hearthside).
2. **The name is a stance, not a feature label.** Nothing, Lapse, noplace, Cara. Each says what the world should feel like. Shotby / Truemade / Signedframe say what the product does, and "proof" in six of them is a feature.
3. **One idea, one beat, two syllables or less.** All 37 are 1-3 syllables, most 2. Rejected names are 2-4 beats of glued parts (Sharekeep, Framekin).
4. **No "by", "proof", "frame", "made", "own", "true", "shot", "photo" scaffolding.** None of the winners use trust-vocabulary in the name, and ours must not use medium-vocabulary either: the product covers video, art, music, design and objects. The category is carried by the domain or the tagline, not the word.
5. **Warm, not corporate.** Cara, Locket, Partiful, Lovable, Humane, Retro. The name could be said to a friend. Courtyard / Lightbox / Hearthside read as stock-photo brands.
6. **Borrow a feeling the user already has.** Retro (nostalgia), Locket (keepsake), Spill (gossip), Saga (story). The name does half the pitch before the screenshot.
7. **Let the domain finish the thought.** `glass.photo`, `divine.video`, `locket.camera`, `read.cv`, `are.na`, `me.sh`. You do not need the .com; you need the word.
8. **Sound is a logo.** Hard or round consonants, easy to say on a podcast, no spelling quiz. Vowel-dropping and "-ly" now read dated. No "AI" suffix.
9. **Unrelated to the protocol.** Bluesky rides its parent's image; the app can too, but a standalone name with a sentence of stance ("a place to...") lets it grow past Bluesky. Skylight/Flashes are describing themselves as clients; a movement needs a brand.
10. **A name Roy can say as a sentence.** "I posted it on ___." "Find me on ___." If the sentence sounds forced, cut it.

## 3. Domain endings modern launches actually use

| Ending | Used by | How it reads | Use for us? |
|---|---|---|---|
| `.app` | retro.app, cara.app, margins.app, bsky.app, linear.app | "this is the product", default modern app ending, HTTPS forced | Yes, medium-neutral, safest primary |
| `.so` | cosmos.so, notion.so | quiet, designer-y, "so" as a word ("Notion dot so") | Yes if word is free |
| `.co` | pagebound.co, themallapp.co | startup-neutral, slightly second-choice | Fallback |
| `.photo` `.camera` `.video` | glass.photo, locket.camera, divine.video | name + medium in one read | No: each narrows us to one medium |
| `.art` | (creator portfolios) [inferred] | on-category for artists and makers | Maybe: covers illustration, design, objects, but not music/video well |
| `.social` | bsky.social, skylight.social, sill.social | "this is a network" | Yes: medium-neutral, on-message for AT Protocol |
| `.cv` | read.cv, posts.cv | creator/portfolio coded | Maybe: fits all creative work |
| `.is` | (Iceland) common in hack names | declarative: "name.is" reads as a sentence | Yes for a stance name |
| `.sh` | me.sh | hacker-cute, dev tool lean | No, too dev |
| `.inc` | corner.inc | tongue-in-cheek corporate | No, we are nonprofit |
| `.im` | shelf.im | informal, "I'm" | Maybe |
| `.fyi`, `.blue`, `.fm`, `.dev` | frontpage.fyi, bluescreen.blue, dazzle.fm, lovable.dev, zed.dev | niche signals (casual / ATProto / music / dev) | `.blue` is a deliberate ATProto-community signal |
| `.xyz` | Gen-Z projects | weak trust signal per domain guides | No |
| `.org` | Wikipedia, Signal, Mozilla | nonprofit, civic | Yes for the nonprofit entity, pair with a short consumer domain |
| `.com` | partiful.com, figma.com, perplexity.ai (no) | still the gold standard, mostly taken | Buy only if a clean one exists |
| `get` / `try` / `join` prefix | getpartiful style, getmightymouse.com | admits the real word is taken; fine for v1 | Fallback, never primary |

### Fast way to cut the 15 (not done)

Say each in the sentence "I posted it on ___" out loud. Drop any that need explanation. Then check: domain (rules 7), trademark in classes 9/42/45, App Store collision, and whether it already means something rude in a major language. Several (Ember, Mosaic, Common, Plain, Okay) are heavily used words: expect to need a category TLD.

## 5. One-line takeaways for the founder

- "Cringe" here means a literal compound that describes a feature. Winners are plain words with a feeling attached.
- Put the trust, proof and open-source promise in the tagline, not the name. The name is a flag, not a spec sheet.
- Nonprofit plus welcoming means avoid anything adversarial (no anti-IG language) or corporate (.inc, "-ly").
